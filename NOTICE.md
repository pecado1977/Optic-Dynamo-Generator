# Notice

This package contains engineering simulations and documentation for a
Walter Russell Optical Dynamo Generator interpretation with an AMCC-1000
Metglas paraformer center.

The included model is conventional electromagnetic simulation software. It is
not evidence of non-classical energy production. Any physical build must be
validated independently with calibrated low-power measurements before
high-power operation is considered.

The repository includes generated CSV and figure outputs so that the latest
reported experiment state can be inspected without re-running the simulator.
